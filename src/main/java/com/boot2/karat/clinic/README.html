1. Problem statement

Build a clinic backend that tracks doctors and appointments. Implement ClinicManager.getAverageAppointmentDurationByType(int doctorId) so it returns a map of appointment type → average duration in minutes.

Rules

  • Count only appointments with status COMPLETED.
  • Ignore SCHEDULED, CANCELLED, and NO_SHOW.
  • Include a type in the map only if that doctor has at least one completed appointment of that type.
  • If the doctor is unknown, or has no completed appointments, return an empty map.

A second helper, getAppointmentStatistics(), returns clinic-wide totals: total appointments, completed count, and no-show rate.

3. What was wrong in the interview attempt

The failing run printed counter6 / average1.0 and then: Expected 35.5 for CONSULTATION. That came from several bugs in getAverageAppointmentDurationByType:

Bug Effect
No filter on doctorId Counts every doctor's completed appointments
No filter on appointmentType Same totals reused for CONSULTATION / FOLLOWUP / EMERGENCY
duration++ instead of adding minutes Duration becomes the count, not the sum of minutes
Integer division duration / counter Average collapses to 1 (then stored as 1.0)
Always put every type Map includes types with zero completed visits
Why average became 1.0: with 6 completed appointments clinic-wide, both counter and duration became 6, so 6 / 6 = 1.

4. Correct solution

Filter by doctor + COMPLETED, sum real durations per type, divide with a double cast, and omit empty types. 
public Map<AppointmentType, Double> getAverageAppointmentDurationByType(int doctorId) {
    Map<AppointmentType, Double> averages = new HashMap<>();
    if (!doctors.containsKey(doctorId)) {
        return averages;
    }

    Map<AppointmentType, Integer> totals = new HashMap<>();
    Map<AppointmentType, Integer> counts = new HashMap<>();

    for (Appointment a : appointments) {
        if (a.doctorId != doctorId) continue;
        if (a.status != AppointmentStatus.COMPLETED) continue;

        totals.merge(a.appointmentType, a.durationMinutes, Integer::sum);
        counts.merge(a.appointmentType, 1, Integer::sum);
    }

    for (Map.Entry<AppointmentType, Integer> entry : totals.entrySet()) {
        AppointmentType type = entry.getKey();
        averages.put(type, (double) entry.getValue() / counts.get(type));
    }
    return averages;
}

Also fixed: no-show rate

In the problem version, noShows / total used integer division (1 / 5 = 0). The solution casts: (double) noShows / total → 0.2.
